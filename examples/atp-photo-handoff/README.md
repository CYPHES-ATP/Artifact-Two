# ATP Photo Handoff Fixture

This fixture is the first Artifact Two verifier example.

It uses a known-good ATP v0.3 bundle generated by CYPHES. The workload is a
photo-organization handoff, not a Coder PR handoff, because it already contains
the complete ATP evidence surface:

- `receipt.json`
- `public-keys.json`
- `envelopes.jsonl`
- `transcript.jsonl`
- `contract.json`
- `leases.json`
- `lease-access-log.jsonl`
- `artifacts/`

The same bundle contract is intended for CYPHES Coder receipts.

Run:

```bash
python3 tools/verify_atp_bundle.py examples/atp-photo-handoff/valid
```
